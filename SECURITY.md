# Security policy

## Reporting a vulnerability

Please report security problems **privately** by email to
[contact@scribyra.com](mailto:contact@scribyra.com), with "Security" in the subject.
Do not open a public issue or pull request for them.

Include what you found, the steps or a proof of concept to reproduce it, the browser
and operating system you used, and which version is affected (the release `web-N`
shown at `https://app.scribyra.com/release.json`, or a commit). We will acknowledge
your report, keep you informed while we fix it, and credit you if you wish.

## Scope

Scribyra is a static browser application: projects are stored and compiled in your
browser. Relevant reports include ways for a project, an imported ZIP or backup, a
TeX package, a comment, an MCP provider or an agent command to run script in the
app, read or change another project, or send project data anywhere without the
person's action. Issues in third-party services or in your own browser profile are
out of scope, but tell us if Scribyra makes them worse.

## Supported versions

Only the latest production release at [app.scribyra.com](https://app.scribyra.com/)
and the `main` branch receive fixes during the public beta.
