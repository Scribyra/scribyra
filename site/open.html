OPEN IN SCRIBYRA

A button that opens your paper

Put an “Open in Scribyra” badge on a GitHub or GitLab repository. One click opens Scribyra, shows where the files come from and how big they are, and imports a copy into that person’s browser when they agree. Nothing is compiled until they choose to.

A public GitHub or GitLab repository (gitlab.com or your own GitLab), a page inside one such as …/tree/main/paper, or an https address of a .zip file that allows downloads from other sites.

Your link

Try the link ↗

What happens when someone clicks it

  • Scribyra opens and shows the source, branch and folder. Nothing is downloaded yet.
  • They choose Check repository: their browser asks GitHub or GitLab for the file list, and Scribyra shows the number of files, their size and anything it will skip, such as Git LFS files, submodules or symbolic links.
  • They choose Import or Import and compile. A copy is made in their browser; nothing is sent back to you or to us.
  • Projects hold up to 512 files and 64 MiB. Files over 16 MiB are skipped. Opening the link again offers the copy they already have.

Only public repositories work for now; private ones will come with the Git plugins. GitHub allows 60 requests an hour per network without signing in, and each check uses two (or three with Git LFS settings). Details are in the link format reference; what the browser contacts is on the privacy page.
