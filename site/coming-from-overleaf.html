Coming from Overleaf?

Overleaf lets you download any of your projects as a ZIP of its source files. Scribyra imports that ZIP as it is, finds the main file, and tells you if anything needs a change. It takes a few minutes.

Scribyra is a separate, independent project. It is not affiliated with Overleaf; this page only describes how to move your own files.

Step by step

  1. Download the source. Open your project in Overleaf and download it as source: Menu → Download → Source (in the newer editor, File → Download as source (.zip)). You get a ZIP of your .tex, .bib, image and other files. You don’t need the PDF.
  2. Open Scribyra. Go to app.scribyra.com. There is no account to create; projects are stored in your browser.
  3. Import the ZIP. Choose Import ZIP on the dashboard (on your first visit, Import a ZIP in the welcome) and pick the file you downloaded. The ZIP is read in your browser and is not uploaded anywhere.
  4. Read the summary. Scribyra shows the main file it chose, your bibliography and image counts, which compiler the project was written for, and anything to adjust, with the fix. Choose a file name in the list to jump to that line.
  5. Compile. Choose Compile now, or Compile (Ctrl + Enter, or ⌘ + Enter on a Mac). The first compile downloads the TeX engine once; after that it also works offline.

pdfLaTeX, XeLaTeX and LuaLaTeX

Overleaf compiles with pdfLaTeX unless a project chooses otherwise. Scribyra always compiles with LuaLaTeX, a modern engine that reads UTF-8 and uses OpenType fonts. Most pdfLaTeX documents compile with it unchanged. Scribyra reads the compiler setting from the project’s latexmkrc or a % !TEX program line, and otherwise from the packages it uses.

In your projectWhat to do
\usepackage[utf8]{inputenc}Nothing. LuaLaTeX ignores it; you can delete it.
\usepackage[latin1]{inputenc} (or another encoding)Save the files as UTF-8 and delete the line. Overleaf already stores files as UTF-8, so usually only the line needs to go.
\usepackage[T1]{fontenc}Works. Deleting it gives you OpenType Latin Modern; use fontspec to choose other fonts.
\pdfoutput=1 and other \pdf… commandsDelete \pdfoutput=1. For the others, add \usepackage{luatex85} at the top.
xeCJK, xltxtra, xunicode, \XeTeX… commandsThese are XeLaTeX-only. Use luatexja-fontspec for Chinese and Japanese; fontspec covers the rest.
fontspec, unicode-math, polyglossiaNothing; they work the same with LuaLaTeX.

What a browser cannot do

  • Shell escape. Packages that run other programs (minted, svg, gnuplottex, pythontex) don’t work. Use listings for code, and export figures as PDF or PNG.
  • EPS images. Convert them to PDF first and upload the PDFs; \includegraphics finds them without the extension.
  • Glossaries. Load glossaries with automake=immediate, or use \printunsrtglossary from glossaries-extra. Bibliographies (Biber and BibTeX) and indexes (makeindex) do work.
  • Custom latexmk rules. Extra steps in a latexmkrc are not run.

What comes across, and what doesn’t

Everything in the source ZIP: .tex files, bibliography files, images, class and style files, folders. Comments, tracked changes, chat and history stay in Overleaf, because the download doesn’t include them. Scribyra has its own comments, suggested changes and history from here on.
