# Scribyra presentation site

The published production site of `scribyra/scribyra`, served at https://scribyra.com/.
The `production` workflow of that repository pushes each deployed release here as
`public/`; `.github/workflows/pages.yml` publishes it. Do not commit here by hand.
The app itself (https://app.scribyra.com/) is the main repository's own Pages site.
See `docs/github-move.md` in the main repository.
