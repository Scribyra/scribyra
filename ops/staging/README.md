# Scribyra staging site

The staging site of `Scribyra/scribyra`, served at https://dev.scribyra.com/. The
`staging` workflow of that repository pushes it here as `public/` on every push to
its `dev` branch; `.github/workflows/pages.yml` publishes it. Do not commit here by
hand. See `docs/delivery.md` in the main repository.
