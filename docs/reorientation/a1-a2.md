# A1/A2 delivery evidence

November 5, 2026. This covers diagnostics and Option 1 changes 1–6 plus the
project title. It does not complete milestone A, R4, or the later command API.

## Behavior and limits

Rust attributes errors to TeX input files, resolves project-relative paths from
the main document and caps reports at 100 issues. The original A1 delivery
counted warnings across all passes; the November 6 regression follow-up below
reverses that choice and counts only the final TeX pass. Missing dependency names remain
in summaries; source locations point to the importing file. The retained real
logs and their provenance are in [fixtures/diagnostics](../../fixtures/diagnostics/README.md).
Unknown locations are omitted from the compact panel. This is log parsing, not TeX expansion;
logs without usable locations cannot provide a source link. The bounds and
warning semantics are documented in [architecture](../architecture.md#compilation).
Package-transfer failures also forward their retained, bounded TeX log and
build-start project context to the same parser, while preserving their failure
category. Input stacks and explicit file/line messages preserve mixed-case TeX
extensions; the browser failure check also covers a renamed `MAIN.TeX`.

Compile and Cancel compilation now occupy separate, fixed positions. Compile
keeps its name and exposes busy/state attributes; Cancel is disabled while idle.
Keyboard and companion cancellation behavior is preserved. The named compilation
status reports outcome, pages and warnings; discarded stale results say pages
are unavailable. Source links, a separately named log button, a hidden-by-default
raw log region, and project titles complete this slice. Notifications have their
own status name. Existing tests now select these exact names rather than the old
Compile/Cancel prefix or an ambiguous unnamed status; their assertions remain.

Every rendered source line has a `data-line` and a title, including blank lines.
AI-mode snapshots preserve their order. CodeMirror remains virtualized. Default
Playwright snapshot mode still omits editable descendants, and snapshot text
still normalizes whitespace. No claim is made about a real model or attachment
to a person's existing browser profile.

## Diagnostics regression follow-up

November 6, 2026. Warning data no longer controls panel visibility. The status
button toggles issues; failed compiles open them automatically. Close and Escape
hide issues and raw logs, restoring focus to status when closing from the panel.
The choice survives successful compiles until the next failure. The panel uses
25dvh with a fixed header and internal scrolling, leaving both working panes
available. Entries show the message followed by a known source location; unknown
lines are omitted. Warning advice appears once. Detailed evidence remains in the
agent report and raw log.

Rust now supersedes earlier warnings at each TeX command boundary, including
missing-glyph evidence. LOG/STDOUT copies deduplicate within that pass; auxiliary
BibTeX/Biber commands do not clear TeX warnings. Unmarked logs remain one pass.
An explicit one-entry runtime filter removes epstopdf's disabled-shell-escape
notice. The raw log is untouched, including resolved rerunfilecheck warnings.
This remains bounded log parsing, not semantic TeX analysis.

The Rust article fixture test, `agent-surface` article assertion and `agent-recipe`
article assertion change from three warnings to zero because the final pass
resolves all three. Persistent warnings now have a dedicated browser regression;
a brand-new default project compiles at 1366×768 with zero warnings and no panel.
Agent recipe text documents the same count/filter rules while retaining its 2,000-byte budget.
Its fixture diagnostics response budget tightens from 18,000 to 4,000 bytes
(the general paginated API bounds remain unchanged).

Validation used this worktree's production `dist`, served only on port 5001.
No TeX runtime download, push, deployment or external-service check was performed.
